# Alpha 0.3.0a1 delivery and remaining work

M1–M5 and bounded DOCX/PPTX/XLSX subcycles are delivered. Unified mixed-file inspection and all-envelope validation close this alpha scope. PDF/OCR, binary/embedded payload analysis, arbitrary archives, Office semantic/rendering coverage and OS process sandboxing remain future work, not hidden successful checks. Current scope has 84 unittest methods and bilingual guides; release validation requires final exact-head CI, clean installation and dependency audit.

The next independent portfolio cycle is the shared OPSEC contract, followed by the validation lab, recovery audit, network audit and Detection Readiness. This queue does not imply background execution. See [unified scope](unified-inspection.md).
