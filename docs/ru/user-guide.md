# Руководство пользователя

Текстовый прототип 0.1.0a1. Запуск из каталога проекта:

```bash
python3 guard.py /path/to/materials --policy policy.json
python3 -m unittest discover -v
```

Политика необязательна: `{"markers":["SyntheticOrg"]}`. Коды выхода: 0 — поддерживаемый текст проверен без находок; 1 — находки; 2 — неполное покрытие или ошибка. Если есть находки и пробелы покрытия, код 1, пробелы сохраняются в JSON. Лимит файла 2 MB, лимит 10000 файлов. Каталоги .git и __pycache__ намеренно исключены; история Git не проверяется. Результат не означает безопасность всех материалов. Отчёт сохраняется перенаправлением stdout в файл за пределами проверяемого каталога. Сам отчёт может раскрывать имена файлов; перед публикацией очистить их. Проверки платформ отслеживаются в GitHub Actions. Поток содержимого не исполняется; symlink пропускаются. Текст проверяется как UTF-8. Нет OCR, PDF/Office/архивов, IPv6 и полного поиска токенов.
