# ADR-001

Статус: предложено; для первого текстового прототипа принято. Python и стандартная библиотека для переносимого CLI; JSON вместо YAML в базовом ядре; unittest для тестов. Это уменьшает зависимости и сохраняет офлайн-работу. Альтернативы: Go удобен для одного бинарника, но усложняет повторное использование Python-интеграций; веб-сервис добавляет передачу чувствительных данных и не требуется для MVP. Версии runtime и сторонних инструментов фиксируются после проверки официальных источников перед CI. Для остальных проектов решение подтверждается после изучения существующего кода.
