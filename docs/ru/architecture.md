# Архитектура

CLI → загрузчик ограниченного объёма → адаптер → проверки → нормализованный JSON → представление отчёта. Проверки — чистые функции; сбор данных отделён от оценки. Контракт содержит schema_version, tool_version, check_id, asset_id, status, severity, evidence, remediation. Статусы: pass/fail/not_tested/not_applicable. Ошибка сборщика всегда сохраняется отдельно. Пути и идентификаторы чувствительны: экспорт для публикации требует отдельной очистки.
