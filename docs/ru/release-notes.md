# Alpha 0.2.0a4: дополнительный движок секретов

Добавлен отдельный CLI publication-opsec-secrets: фиксированные версия/хеш, ограниченная UTF-8 копия, преобразование без исходных совпадений и явные состояния недоступности. Основная схема остаётся 0.2; формат адаптера secrets-0.1 не принимается основным валидатором. Основные Action/hook не меняются. Поставляются восемь тестовых методов и синтетическая проверка реального движка на Linux. См. [адаптер](secret-adapter.md).

# Обновление интеграций CI/pre-commit

Поставляются составной Action, hook с явным каталогом, runner и синтетические проверки. Коды 1/2 завершают барьер ошибкой; Action сохраняет JSON вне области и не перезаписывает файлы. Версия инструмента остаётся 0.2.0a3, контракт 0.2; правила сканера не меняются. Специализированный адаптер ещё не реализован. См. [руководство интеграций](integrations.md).

# Alpha 0.2.0a3: устанавливаемый CLI

Поставляются конфигурация wheel, две консольные команды, схема, дополнительные зависимости валидатора и проверка установки в чистом окружении. Ядро сканера не требует сторонних библиотек. Старым командам запуска нужен соседний пакет. Контракт остаётся 0.2. Проверка сравнивает хеши двух wheel с фиксированной датой; независимая воспроизводимость на разных платформах и публикация в PyPI не заявляются. См. [установку](installation.md).

# Alpha 0.2.0a2: валидация отчётов

## Реализовано

- Поставляемая схема ответа Draft 2020-12 для отчёта и ошибки запуска.
- Отдельный офлайн-валидатор с межполевыми условиями и кодами сканера 0/1/2; неверная/недоступная валидация даёт 3.
- Строгий UTF-8 JSON: повторные ключи, нестандартные константы, symlink, специальные файлы, пределы размера и глубины.
- Безопасная ограниченная диагностика, 15 размеченных синтетических ответов, 15 тестов валидатора и автоматическая проверка документации.
- Подробные инструкции RU/EN по установке, интеграции, примерам, диагностике и ограничениям.

Версия отчёта остаётся 0.2: его форма не меняется. Версия инструмента — 0.2.0a2. Поведение сканера сохранено относительно a1, кроме отображаемой версии. Полным тестам нужны зависимости валидатора; тестам только сканера они не нужны. Валидация отчёта не подтверждает исходные байты и безопасность публикации. Эти изменения кода не публикуют GitHub release/tag.

## Состояние alpha 0.2.0a1

### Изменения 0.2.0a1

- Проверка точного `.env`, строгая UTF-8 политика с лимитами размера и маркеров.
- Общий бюджет чтения, лимиты находок и каталогов; кэш позиций строк.
- Контракт 0.2: действующие лимиты, счётчики, остановка и явные исключения.
- Пустая область и исключённые каталоги больше не дают полное покрытие.
- 22 регрессионных теста; двуязычные инструкции CLI, перехода и лимитов.
- Бюджеты не гарантируют предел общей памяти процесса или времени выполнения.


### Что входит в код

Пять проверок UTF-8 текста: RFC1918 IPv4, домены `.local`/`.internal`, home paths, заголовки приватных ключей и буквальные маркеры политики. JSON содержит скрытые совпадения и зарегистрированные пробелы. Файлы не изменяются, сетевые запросы при анализе отсутствуют.

### Известные ограничения

- Нет PDF/Office/OCR, изображений, архивов, EXIF и истории Git.
- Нет IPv6, полного поиска токенов, проверки активности ключа и автоматического исправления.
- Нет полной защиты от конкурентной подмены дерева и hardlink.
- Нет готового installer/pip-пакета/composite Action или подтверждённой матрицы всех ОС и CPU.
