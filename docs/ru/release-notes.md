# Заметки к выпуску 0.1.0a1

Локальный прототип; публичного релиза и CI нет. Реализованы PUB-001–PUB-005 для UTF-8 текста. Восемь локальных тестов прошли в Linux на Python стандартной библиотеки. Матрица проверок задаёт требования; не все критерии полного цикла уже выполнены. GitHub Action, интеграции Gitleaks/TruffleHog и проверка бинарных документов ещё не реализованы. Следующий этап: усиление обхода недоверенного дерева, расширение тестов, упаковка CLI и CI, проверка на macOS/Windows, подготовка alpha-выпуска после проверок.
