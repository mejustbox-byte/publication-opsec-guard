# Publication OPSEC Guard: Требования

Локальная проверка материалов до публикации.

Текстовый CLI; JSON-отчёт без исходных совпадений; лимиты; политика маркеров. ZIP/PDF/Office, OCR и адаптеры Gitleaks отложены.

Все операции только чтение. Нет автоматического исправления. Входные данные остаются локально. Примеры исключительно синтетические. Критерии приёмки: каждый ID матрицы имеет положительный, отрицательный и ошибочный вход; неизвестные и недоступные данные не считаются успешной проверкой. Неподдерживаемые форматы перечисляются в отчёте. Лимиты ресурсов настраиваются с безопасными значениями по умолчанию.
