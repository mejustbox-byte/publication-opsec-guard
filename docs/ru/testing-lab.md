# Проверки и лаборатория

Каждая проверка: небезопасный вход → fail; безопасный вход → pass; отсутствующее доказательство → not_tested; подтверждённая неприменимость → not_applicable. Измерять TP/FP/FN/TN на версионированном наборе, не придумывать процент точности. Отдельно тестировать повреждённый JSON, Unicode, лимиты, symlink и отсутствие прав. Реальный стенд фиксирует ОС, версии, конфигурацию, дату, SHA и обезличенное доказательство; фикстуры не заменяют стенд. Никакие платные ресурсы автоматически не создаются.
