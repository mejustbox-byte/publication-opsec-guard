# Модель угроз

Секреты и раскрытие инфраструктуры в документах; недоверенные файлы; обход через symlink; утечка через отчёт.

Активы: исходные данные, доказательства, локальная политика, итоговые отчёты. Границы доверия: вход → парсер → нормализованная модель → проверки → экспорт. Защита: ограничение размера, запрет исполнения содержимого, очистка доказательств, отсутствие сетевых запросов по умолчанию. Остаточный риск: неполное покрытие форматов и ложные срабатывания; ручная проверка остаётся обязательной для спорных результатов.
