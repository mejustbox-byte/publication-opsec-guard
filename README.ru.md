# Publication OPSEC Guard

**Локальная проверка публикации · Только чтение · Явное покрытие · MIT**

Проверяет подготовленные материалы на внутренние адреса, имена, пользовательские пути, заголовки ключей, настроенные маркеры и выбранные метаданные Office. Отчёты скрывают совпадения и сохраняют непроверенные области. **0.3.0a1 — alpha** с ограниченной заявленной областью.

[English](README.en.md) · [Полное руководство](docs/ru/index.md) · [Единый запуск](docs/ru/unified-inspection.md) · [Заметки выпуска](docs/ru/release-notes.md)

## Поддержанные проверки

| Компонент | Реализовано |
|---|---|
| UTF-8 текст | Пять правил раскрытия, строгая локальная политика, ограниченный обход |
| DOCX/PPTX/XLSX | Ограниченный XML-текст и выбранные метаданные; объединение rich-text runs |
| Дополнительный Gitleaks | Установленный пользователем бинарник 8.24.2/хеш; специализированный поиск только в тексте |
| Единый запуск | Смешанный каталог, один общий отчёт и явные состояния вложенных проверок |
| Валидатор | Основные, документные, секретные и общие схемы с межполевыми проверками |
| Интеграции | Текстовые Action/pre-commit; смешанная проверка через единый CLI |

## Установка и запуск

Нужен Python 3.12+ с текущими исправлениями безопасности; CI проверяет Python 3.13. Из проверенной копии:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install '.[validation]'
.venv/bin/publication-opsec-inspect prepared-materials > publication-report.json
.venv/bin/publication-opsec-validate publication-report.json
```

На Windows используйте `.venv\Scripts\python.exe` и `.venv\Scripts\publication-opsec-inspect.exe`. Отчёты/приватные политики храните вне проверяемого каталога. Для одного сканирования установите `.` без дополнительной группы. Wheel/исходный пакет и SHA256SUMS поставляются через GitHub Releases; PyPI не публикуется.

| Код | Значение |
|---|---|
| 0 | Нет находок и записанных пробелов в заявленной области |
| 1 | Есть находки; покрытие может быть неполным |
| 2 | Неполное покрытие или ошибка входа без находок |
| 3 | Только валидатор: неверный отчёт/недоступная валидация |

## Границы alpha

PDF/OCR, произвольные архивы, бинарные вложения/медиа и рендеринг Office не проверяются. Формулы читаются как текст и не вычисляются. Специализированный поиск секретов не покрывает XML Office: его запрос оставляет явные документные пробелы. Реальный Gitleaks проверен только на Linux. Ноль не гарантирует отсутствие секретов и не разрешает публикацию. Пути остаются идентифицирующими метаданными.
